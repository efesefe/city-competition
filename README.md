# City Competition

Realtime Türkiye map game for football fans — claim provinces for your Kabile.

## Active stack slice (Expo + Fastify)

Season 0 locked architecture lives under **`apps/`**:

- **`apps/client`** — Expo (iOS / Android / web)
- **`apps/api`** — Fastify TypeScript API + WebSocket ownership digest

**How to run (web):** see [`apps/README.md`](apps/README.md).

## Legacy tree

`frontend/` (Next.js) and `backend/` (Go) are earlier explorations. Prefer `apps/` for new Season 0 work.
